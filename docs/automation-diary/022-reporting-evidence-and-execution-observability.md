# Automation Diary #022 — Reporting, Evidence, and Execution Observability

**Version:** v0.22.0

## Goal

Introduce a consistent framework-level contract for execution traceability, reports, diagnostic evidence, and CI artifact organization.

## Added

- Central observability configuration
- Evidence-root resolution
- Report-root resolution
- Traceable execution identifiers
- Deterministic evidence naming
- Execution metadata
- Structured observability logging
- Framework-level observability tests
- Observability usage template
- Reporting and evidence architecture documentation

## Engineering decision

A test result is useful only when engineers can understand what executed and where to find the evidence needed for diagnosis.
